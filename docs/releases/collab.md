# Collab

**Hosted feature release · September 25, 2026**

Create shared workspaces for up to 12 people total, invite participants by link, and work in shared conversations. Each person pays for their own requests.

## What ships and limitations

An invite link grants access to the workspace while valid; share it with intended participants. Membership controls apply to shared conversations. The limit includes the owner. Collaboration does not pool prepaid balances.
