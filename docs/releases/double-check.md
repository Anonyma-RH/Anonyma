# Double-check This

Ask another provider’s model for a second opinion on an answer, using Symposium. Open Double-check this under an answer, choose a reviewer and review its estimated extra cost, then explicitly ask. The original answer stays unchanged. This is another opinion, not fact verification; the reviewer can also be wrong.

Provider diversity refers to model makers, not the gateway hosting endpoint. Known aliases and model families are normalized. Unknown makers are excluded, and availability depends on the callable models in the catalog.

The question and answer use the current conversation’s Veil masking policy. Private and off-record checks remain unsaved. Saved checks link to their source conversation: deleting the source deletes its checks, shortening source retention shortens them, and removal from a shared conversation removes that member’s saved checks. Deadlines are never extended through the source.

A second opinion is a separate paid request from your personal balance, including when the source is a shared chat. The panel discloses this before you ask. Its estimate is not a guaranteed final charge. Partial output can be billed when stopped. The release film uses sample answers and an illustrated interface.
