# Gift Links

**Code release · 27 September 2026 · hosted deployment pending CI**

A link anyone can claim, without giving the sender a username or email.

[Public release commit](https://github.com/Anonyma-RH/Anonyma/commit/d9380de0539912141e0900a91d986cfa5854def2). The release code is published. The hosted rollout is pending GitHub Actions billing recovery; do not treat the local footage as proof that the hosted feature is live.

## Demonstrated behavior

A gift of 100 synthetic local credits was created, its QR card inspected, then cancelled. The balance returned.

## Limits

Unclaimed credits return after 30 days. Cancelling a gift still counts toward the day’s spending limit. Gift credits have no cash value and cannot be refunded to cash.
