# History Search & Library Actions

Search saved conversations, reopen accessible source chats, and review a fresh quote before rerunning supported generated media. Reruns require an explicit action and use current model availability and prices.

Private, ephemeral and auto-deleting conversations are excluded from history search. Source access is checked again when opening a result. Unavailable sources or unsupported old generation settings stay unavailable; no substitute model is silently selected. Source deletion does not erase previously saved permanent generated media.
