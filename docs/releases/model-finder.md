# Model Finder & Presets

Search the models available to the current task by name, provider or capability. Choose Cheap, Balanced, Best quality or a specific model. Explicit choices are remembered per workspace mode in this browser; a temporary fallback does not overwrite the preference. Quotes and Send use the selected eligible model.

Cheap uses published prices. Balanced chooses a middle popular price tier where available. Best quality is a finite editorial task recommendation, not a benchmark or price ranking. If no reviewed recommendation is available for the task and privacy settings, it is shown as unavailable; manual selection remains available. The policy must be reviewed as the catalog changes.

Displayed picker prices are sample estimates using stated standard-rate assumptions; the separate request estimate depends on the actual request and current billing terms. Private, image-capability and release restrictions still apply. Availability depends on the live catalog. The film shows illustrative sample models and prices.
