# Uncensored Models

Uncensored Models is live at [askanonyma.com/workspace/uncensored](https://askanonyma.com/workspace/uncensored).

A dedicated Uncensored section brings together models explicitly labelled uncensored by their providers. Choose a model from its own picker and use the same prepaid credit balance as Chat and Code & Build. Conversations are saved in their own section and billed per token at the selected model’s displayed rates.

The initial collection includes Venice Uncensored 1.2, Venice Uncensored (Dolphin Mistral 24B), Venice Uncensored Role Play, Gemma 4 Uncensored and GLM 4.7 Flash Heretic. These initial models are served through Venice. The collection is provider-independent and can include other supported models after verification; an uncensored label does not guarantee every possible request will be answered.

The normal Chat picker keeps its ten MVP models. Image, full catalog, audio, video, collaboration, developer API and referral releases remain gated.
